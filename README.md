\# ExamGuard

\## Online Exam Monitoring and Integrity Analytics Platform



ExamGuard is an online examination monitoring and integrity analytics platform designed to support secure and reliable online examinations.



\## Features



\- Online examination system

\- Candidate registration and login

\- Examination rules and system checks

\- Candidate verification

\- Government ID verification

\- Selfie capture

\- Room scanning

\- Face detection

\- Head pose monitoring

\- Suspicious activity detection

\- AI-based integrity analysis

\- Integrity scoring

\- Evidence collection

\- Faculty dashboard

\- Candidate dashboard

\- Examination results

\- Integrity reports

\- Analytics and visualization
