\# ExamGuard Agile Documentation



\## 1. Development Methodology



The ExamGuard project follows an Agile-inspired development approach.



The project is divided into smaller modules and developed incrementally.



\## 2. Product Vision



Develop an online examination platform that supports candidate verification, examination monitoring, evidence collection, and integrity analytics.

\## 5. Definition of Done



A feature is considered complete when:



\- The feature is implemented.

\- The feature is tested.

\- Major errors are resolved.

\- The feature integrates with the application.

\- Documentation is updated.



\## 6. Agile Review



At the end of each development iteration:



\- Completed work is reviewed.

\- Remaining tasks are identified.

\- Issues are documented.

\- Improvements are planned for the next iteration.



\## 7. Retrospective



The development process can be improved by:



\- Testing modules earlier.

\- Maintaining clear documentation.

\- Using version control regularly.

\- Separating application modules.

\- Reviewing errors after every development iteration.
